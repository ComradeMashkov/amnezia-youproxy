# AmneziaVPN через VPS и SOCKS5-прокси

Инструкция помогает настроить цепочку:

**Устройство → AmneziaVPN с XRay → свой VPS → SOCKS5-прокси → интернет**

Сайты увидят внешний IP прокси. В качестве примера используется YouProxy, но подойдёт другой прокси с SOCKS5 и авторизацией по логину и паролю.

Скрипт настраивает только XRay. Трафик AmneziaWG, OpenVPN и других протоколов не пойдёт через этот прокси автоматически. Для этой схемы в приложении нужно выбрать XRay.

## Что понадобится

- VPS с публичным IPv4, Ubuntu 24.04 и SSH-доступом. На сервере должны работать Docker и Python 3. AmneziaVPN обычно устанавливает Docker во время настройки сервера.
- Установленное приложение [AmneziaVPN](https://amnezia.org/).
- SOCKS5-прокси: адрес, порт SOCKS, логин и пароль. Порт HTTP для этого скрипта не подходит.
- Доступ к портам VPS. Для SSH обычно используется TCP 22, для XRay по умолчанию TCP 443. Проверьте также правила у хостинг-провайдера.

Требования AmneziaVPN к серверу приведены в [документации](https://docs.amnezia.org/ru/documentation/supported-linux-os-for-vps/). Прокси должен разрешать подключения с IP вашего VPS, если у провайдера включён список разрешённых адресов.

## 1. Установите XRay на VPS

1. Откройте AmneziaVPN и добавьте свой VPS как Self-hosted VPN. Введите IP сервера и данные SSH.
2. При ручной установке выберите XRay. Если сервер уже добавлен, откройте его настройки и установите XRay в списке протоколов. Подробности есть в [инструкции Amnezia](https://docs.amnezia.org/ru/documentation/instructions/install-vpn-on-server/).
3. Выберите XRay в приложении, подключитесь и проверьте, что сайты открываются. На этом этапе внешний IP обычно совпадает с IP VPS.

Если используется AmneziaVPN 5.1.0.6 и серверный XRay 26.10.31, проверьте параметр **Fingerprint** в настройках безопасности XRay. При значении `hellochrome_120` выберите `firefox` или `safari` и сохраните настройки. Эти варианты рекомендует [документация Amnezia](https://docs.amnezia.org/ru/documentation/instructions/xray-settings/). Обновите ключи на других устройствах, если приложение сообщит об этом.

## 2. Скопируйте скрипт на сервер

Откройте терминал в папке с этим проектом. На macOS и Linux можно использовать «Терминал», на Windows подойдёт PowerShell. Замените `IP_СЕРВЕРА` на адрес своего VPS:

```sh
scp configure_proxy.py root@IP_СЕРВЕРА:/root/configure_proxy.py
```

При первом подключении SSH покажет отпечаток ключа сервера. Сверьте его с данными провайдера. Затем введите пароль SSH, если используете вход по паролю. При вводе пароль не отображается.

Если SSH работает на нестандартном порту, добавьте в команду `scp` параметр `-P НОМЕР_ПОРТА`. Для входа через обычного пользователя вместо `root` скопируйте файл в его домашнюю папку и запускайте через `sudo`.

## 3. Настройте прокси

Подключитесь к VPS:

```sh
ssh root@IP_СЕРВЕРА
```

Для нестандартного порта SSH используйте `ssh -p НОМЕР_ПОРТА root@IP_СЕРВЕРА`. Запустите скрипт:

```sh
python3 /root/configure_proxy.py
```

Скрипт спросит адрес, SOCKS5-порт, логин и пароль прокси. Пароль при вводе не отображается и не передаётся в командной строке. Скрипт проверит вход в прокси и запрос к `api.ipify.org`, затем покажет внешний IP. После этого он сохранит резервную копию настроек XRay, проверит новый конфигурационный файл и перезапустит контейнер `amnezia-xray`.

Скрипт рассчитан на стандартный XRay с одним прямым выходом. Если в XRay уже есть особые DNS-настройки, правила маршрутизации или несколько выходов, скрипт остановится и не будет их перезаписывать. Для повторного запуска сначала восстановите исходную конфигурацию по разделу об откате.

## 4. Проверьте подключение

1. На устройстве выберите XRay в AmneziaVPN и подключитесь.
2. Откройте [api.ipify.org](https://api.ipify.org/). IP должен совпасть с внешним IP, который скрипт показал при проверке прокси. Это может быть другой IP, чем адрес для подключения к прокси, если провайдер использует шлюз.
3. Откройте несколько сайтов. Проверьте каждое устройство отдельно и убедитесь, что в приложении выбран именно XRay.

Если включено разделение трафика, часть сайтов или приложений может обходить VPN. Чтобы проверить весь трафик устройства, настройте соответствующий режим в AmneziaVPN и дополнительно проверьте DNS и IPv6 на выбранном вами сервисе проверки утечек. Один IP-тест не доказывает отсутствие утечек для всех приложений и протоколов.

## Если что-то не работает

- **Ошибка проверки прокси.** Проверьте SOCKS-порт, логин, пароль, срок оплаты и разрешённый у провайдера IP VPS. Не используйте HTTP-порт вместо SOCKS-порта.
- **AmneziaVPN долго подключается.** Проверьте Fingerprint по инструкции выше, доступность порта XRay и настройки клиента. Ключи, выданные до изменения настроек, могут требовать обновления.
- **После изменения настроек XRay в приложении снова показывается IP VPS.** AmneziaVPN могла перезаписать серверную конфигурацию. Проверьте настройки и при необходимости восстановите исходную конфигурацию и повторно запустите скрипт. Не пересоздавайте протокол без необходимости: это может изменить клиентские ключи.
- **Некоторые приложения или игры не работают.** Эта конфигурация блокирует UDP, кроме DNS-запросов, которые XRay обрабатывает отдельно. SOCKS5 здесь используется для TCP. Приложениям, которым нужен UDP, может понадобиться другая схема.
- **Нужны сведения о состоянии.** На VPS выполните `sudo docker ps` и `sudo docker exec amnezia-xray xray run -test -config /opt/amnezia/xray/server.json`. Синтаксическая проверка не подтверждает работу VPN целиком.

## Откат

Покажите резервные копии на сервере:

```sh
sudo docker exec amnezia-xray sh -c 'ls -lt /opt/amnezia/xray/server.json.backup-*'
```

Выберите нужную копию. В следующей команде замените `server.json.backup-ИМЯ` на точное имя файла из списка:

```sh
sudo docker exec amnezia-xray cp /opt/amnezia/xray/server.json.backup-ИМЯ /opt/amnezia/xray/server.json
sudo docker restart amnezia-xray
```

Проверьте подключение XRay и IP. После восстановления исходной конфигурации трафик обычно выходит напрямую через VPS. Резервная копия возвращает все настройки XRay на момент её создания, поэтому более поздние изменения клиентов тоже будут отменены.

## Безопасность и публикация

Не публикуйте SSH-пароль, логин и пароль прокси, клиентские ключи, QR-коды и настоящие конфигурации сервера. Скрипт сохраняет пароль прокси в серверном файле XRay, потому что XRay должен передавать его прокси. Резервные копии также могут содержать ключи и пароли. Храните их только на сервере с ограниченным доступом, не добавляйте их в Git.

SOCKS5 сам по себе не шифрует участок между VPS и прокси. Провайдер прокси может видеть адреса запрашиваемых сайтов, а при использовании незашифрованного HTTP и их содержимое. Используйте HTTPS и доверенного поставщика прокси.

Для проверки скрипта разработчиком из папки проекта:

```sh
python3 -m unittest discover -s tests -v
```
